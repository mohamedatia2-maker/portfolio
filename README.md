# 🚀 Mohamed Atia — Personal Portfolio

A sleek, responsive, and bilingual portfolio showcasing the work, experience, engineering projects, and software expertise of **Mohamed Mohamed Atia Mohamed** — Mechatronics Engineer & Full-Stack Developer.

🌐 **Live Demo:** [https://mohamedatia2-maker.github.io/portfolio/](https://mohamedatia2-maker.github.io/portfolio/)

---

## ✨ Features

- **🌐 Bilingual Support:** Instant toggle between English and Arabic (RTL support).
- **🌓 Dark / Light Theme:** Custom dynamic color schemes with smooth transitions.
- **🎨 Interactive Canvas:** Cybernetic/particle animated canvas background.
- **📱 Fully Responsive:** Tailored layout for desktop, tablets, and mobile devices with a slide-out drawer menu.
- **🛠️ Showcase Sections:**
  - **About:** Background, core principles, and education.
  - **Skills:** Interactive category breakdowns (Mechatronics, Software, Tools).
  - **Experience:** Career milestones and engineering leadership.
  - **Projects:** Interactive project showcase with previews and details.
  - **Certifications & Upgrades:** Accreditations and technical badges.
  - **Contact:** Direct links and reach-out options.

---

## 🛠️ Built With

- **HTML5:** Semantic, accessible structure.
- **Vanilla CSS3:** Custom design tokens, glassmorphism, responsive CSS grid/flexbox, animations.
- **Vanilla JavaScript (ES6+):** Theme switcher, language localization dictionary, particle canvas physics, and smooth scroll navigation.
- **Fonts:** Cairo, Inter, Fira Code (via Google Fonts).

---

## 🚀 Getting Started

To view the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mohamedatia2-maker/portfolio.git
   cd portfolio
   ```

2. **Open `index.html`:**
   Double click `index.html` or serve with any static web server (e.g. VS Code Live Server or `npx serve`).
